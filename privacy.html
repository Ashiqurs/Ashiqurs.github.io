Privacy policy

homelab-rclone is a private backup tool. Its only user is its owner, Ashiqur.

The tool uses only the Google Drive https://www.googleapis.com/auth/drive.file scope and is configured to access only files it creates in the owner’s own Google Drive.

Backup data is encrypted on the owner’s server before upload to Google Drive. Data is not sold or shared with other people, advertisers, or other services. Google Drive is used solely to store the owner’s encrypted backups.

This informational website is hosted by GitHub Pages; GitHub may process technical request data to serve these pages. No analytics or tracking scripts are added by this site.
